XHS Pro System

小紅書捷徑後端、啟用碼、裝置綁定、下載服務與管理後台。此版本正在依照「小红书助手 pro v4.7」流程逐項建立相容功能。

進入管理後台服務狀態

啟用碼

支援期限、永久授權、停用、刪除與一碼多裝置上限。

裝置綁定

保存捷徑傳入的 device_id、平台、首次與最後使用時間，並可從後台解除綁定。

捷徑 API

保留原流程使用的 /xhszshq?a=&b=&c=&device_id= 呼叫格式。

公開媒體下載測試

目前保留原專案的公開媒體下載功能，後續會專注補齊小紅書圖片、影片、Live Photo 與動圖工廠流程。
